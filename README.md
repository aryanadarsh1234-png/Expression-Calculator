# Expression-Calculator

A modern and responsive **Scientific Calculator** built using **HTML**, **CSS**, and **JavaScript**. It performs basic arithmetic operations as well as several scientific calculations through an intuitive and clean user interface.

## 🚀 Features

- ➕ Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Modulus

- 📐 Scientific functions
  - Sine (`sin`)
  - Cosine (`cos`)
  - Tangent (`tan`)
  - Logarithm (`log`)
  - Natural Log (`ln`)
  - Pi (`π`)
  - Power (`xʸ`)
  - Parentheses support

- 🎨 Modern dark-themed UI
- 📱 Responsive design
- ⌫ Backspace/Delete functionality
- 🧹 Clear (AC) button
- ⚡ Instant calculation

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/Scientific-Calculator.git
```

2. Navigate to the project folder

```bash
cd Scientific-Calculator
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
